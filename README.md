Machine Learning 

📚 This repository contains my journey of learning fundamental machine learning algorithms and techniques. Each topic is organized in individual folders for easy navigation and understanding. Below is an overview of what this repository covers:

📑 Contents

⚙️ Data Preprocessing

Techniques for cleaning and preparing data for analysis.

Handling missing values, encoding categorical data, and feature scaling.

📈 Linear Regression

Single Variable:

Simple linear regression with one independent variable.

Folder: linear_regression_single_variable

Multiple Variables:

Linear regression with multiple independent variables.

Folder: linear_regression_multiple_variables

📊 Polynomial Regression

Using polynomial features to fit non-linear datasets.

Folder: polynomial_regression

🔑 Logistic Regression

Binary Classification:

Logistic regression for problems with two classes.

Folder: logistic_regression_binary

Multiclass Classification:

Extending logistic regression to handle multiple classes.

Folder: logistic_regression_multiclass

🌳 Decision Tree

Understanding decision tree algorithms for classification and regression.

Folder: decision_tree

🌲 Random Forest

Ensemble learning technique using multiple decision trees.

Folder: random_forest

📘 Naive Bayes Classifier

Probabilistic classifier based on Bayes' theorem.

Folder: naive_bayes

📏 Support Vector Machine (SVM)

Understanding SVMs for classification and regression tasks.

Folder: support_vector_machine

📂 Training and Testing

Splitting datasets into training and testing sets.

Evaluating model performance and avoiding overfitting.

Folder: training_and_testing
